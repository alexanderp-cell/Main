# Сверка склада поставщика (GEM) ↔ ТАЗ / ТУЗ

Скрипт `reconcile_supplier_vs_market.py` сопоставляет остатки поставщика с рыночным спросом из ТАЗ (заказы) и ТУЗ (запросы).

## Входные данные (`data/`)

| Файл | Содержание |
|------|------------|
| `supplier_LLP.xlsx` | GEM LLP Inventory Report (серийный, Cycles Rem.) |
| `supplier_Available_Units.xlsx` | Available Units (PN / Condition / QTY) |
| `TAZ_27.07.2026.xlsx` | ТАЗ полный файл 27.07.2026 |
| `TUZ_31.07.2026.xlsx` | ТУЗ 2026 полный файл 31.07.2026 |

## Запуск

```bash
python3 reconcile_supplier_vs_market.py
```

Результат: `output/Supplier_vs_TAZ_TUZ_sverka.xlsx`

## Листы отчёта

1. **Сводка** — покрытие, потенциальная выручка
2. **Сверка по P_N** — все уникальные P/N склада с сигналами ТАЗ/ТУЗ
3. **LLP серии (детально)** — серийные LLP с рыночным спросом
4. **Нет в рынке** — позиции без заказов/запросов
5. **Методика** — правила нормализации и скоринга
