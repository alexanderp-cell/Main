# Main

## Справочник типов ВС

Учебный справочник гражданской авиации лежит в каталоге `handbook/`. Откройте `handbook/index.html` в браузере: сборка и сервер не нужны.

Текущий том — только Boeing, файл `handbook/boeing.pdf`. Восемь семейств: 707 и 720, 727, 737, 747, 757, 767, 777, 787. На семейство одна глава: фотография, схема габаритов в метрах, одно сечение фюзеляжа и таблица пассажирских моделей. Грузовые варианты не включены. Оглавление и закладки PDF открывают семейство. Страница `handbook/index.html` даёт ссылку на скачивание. Фигура в проходе имеет рост 175 см.

Цифры — типовые опубликованные значения представительной модификации. Сечения схематические. Для конкретного борта действуют РЛЭ и документация эксплуатанта.
