# Обновление складских остатков авиационных запчастей

Автоматизация ежемесячного приведения неструктурированной выгрузки складских
остатков (`ОСТАТКИ.xlsx`) к виду файла-образца (`ОБРАЗЕЦ.xlsx`).
Результат сохраняется в `ГОТОВЫЕ_ОСТАТКИ.xlsx`.

## Что делает скрипт

- Оставляет только «зелёные» строки (заливка `00FF00`) с чёрным текстом;
  красные, жёлтые, фиолетовые и прочие строки, а также строки с не-чёрным
  шрифтом отбрасываются.
- Раскладывает данные по столбцам образца:
  `Part Number | Alt. PN | DESCRIPTION | Quantity | Condition | AC Type`.
- Чистит партийные номера: убирает служебные слова (`STK`, `MOW`, `STOCK`,
  `MOSCOW`, `PN`, `P/N`, `ALT`, `QTY`, `PCS`, `EA`, названия складов и т.п.),
  комментарии и кириллицу. Несколько альтернативных номеров пишутся через запятую.
- Удаляет кириллицу из всех значений (в т.ч. `В737` → `B737`).
- Сортирует позиции по типам самолётов в порядке образца, внутри типа —
  по основному Part Number. Позиции с неопределимым типом уходят в конец.
- Полностью сохраняет оформление образца (заголовки, шрифты, заливки, границы,
  ширину столбцов, высоту строк, выравнивание, форматы чисел).

Исходные файлы `ОБРАЗЕЦ.xlsx` и `ОСТАТКИ.xlsx` не изменяются.

## Запуск

```bash
pip install -r requirements.txt
python3 generate_ready_stock.py
```

После выполнения появится файл `ГОТОВЫЕ_ОСТАТКИ.xlsx`.
