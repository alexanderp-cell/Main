# Main

## Справочник типов ВС

Учебный справочник гражданской авиации лежит в каталоге `handbook/`. Откройте `handbook/index.html` в браузере: сборка и сервер не нужны.

Текущий том — только Boeing, файл `handbook/boeing.pdf`. Шесть семейств: 737, 747, 757, 767, 777 и 787. Каждое семейство начинается с нового листа: на первом листе фотография целиком и чертёж с видами (Wikimedia Commons, Julien Scavini, CC BY-SA 3.0). Дальше одна схема салона и таблицы: характеристики с дальностью в километрах и годы производства, двигатели и ВСУ с производителем и моделью, шасси. Оглавление и закладки PDF открывают семейство. Страница `handbook/index.html` даёт ссылку на скачивание.

Цифры — типовые опубликованные значения представительной модификации. Сечения схематические. Для конкретного борта действуют РЛЭ и документация эксплуатанта.
