## Справочник типов ВС

Учебный справочник гражданской авиации лежит в каталоге `handbook/`. Откройте `handbook/index.html` в браузере: сборка и сервер не нужны.

Каталог открывается разделом Boeing: 737-800/MAX 8, 757-200, 767-300ER, 787-9, 777-300ER и 747-8. Фильтр «Все производители» добавляет остальные 15 семейств, Boeing остаётся первым блоком. У каждого типа — характеристики, годы выпуска, двигатели, ВСУ, устройство шасси и поперечное сечение фюзеляжа. Фигура в проходе имеет рост 175 см. Страница «Сечения в одном масштабе» показывает все контуры рядом.

Цифры — типовые опубликованные значения представительной модификации. Сечения схематические. Для конкретного борта действуют РЛЭ и документация эксплуатанта.
