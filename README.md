## Справочник типов ВС

Учебный справочник гражданской авиации лежит в каталоге `handbook/`. Откройте `handbook/index.html` в браузере: сборка и сервер не нужны.

В справочнике 21 семейство: региональные турбовинтовые и реактивные, узкофюзеляжные, широкофюзеляжные и двухпалубные. У каждого типа — характеристики, годы выпуска, двигатели, ВСУ, устройство шасси и поперечное сечение фюзеляжа. Фигура в проходе имеет рост 175 см. Страница «Сечения в одном масштабе» показывает все контуры рядом.

Цифры — типовые опубликованные значения представительной модификации. Сечения схематические. Для конкретного борта действуют РЛЭ и документация эксплуатанта.
