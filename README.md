# Еженедельные отчёты по заказам клиентов

Генератор Excel-отчёта по статусу заказов клиента на основе выгрузки ТАЗ.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python3 generate_report.py \
  --input /path/to/TAZ.xlsx \
  --client Utair \
  --date 17.07.2026
```

По умолчанию отчёт сохраняется в `reports/Utair статус 17.07.2026.xlsx`.

### Параметры

| Параметр | Описание |
|----------|----------|
| `--input`, `-i` | Путь к файлу ТАЗ (.xlsx) |
| `--output`, `-o` | Путь к выходному файлу (необязательно) |
| `--client`, `-c` | Имя клиента в колонке `Customer` (по умолчанию: `Utair`) |
| `--date`, `-d` | Дата отчёта в формате `ДД.ММ.ГГГГ` (для имени файла и расчёта «более 30 дней») |

## Структура отчёта

| Лист | Содержимое |
|------|------------|
| **Total** | Сводка: «В работе» и «Отгружено» |
| **Отгружено** | Статусы `3 SHIPPED` и `4 FINISHED` с остатком к оплате ≠ 0 |
| **В работе** | Статусы `1 NOT PAID`, `2 PAID`, `6 TROUBLE` |

На каждом листе с позициями первая строка данных — итоговая строка `SAMPLE` с суммами.

Данные берутся за всё время, без фильтра по периоду.
