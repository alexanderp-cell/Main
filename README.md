# Main

## Справочник типов ВС

Учебный справочник гражданской авиации лежит в каталоге `handbook/`. Откройте `handbook/index.html` в браузере: сборка и сервер не нужны.

Текущий том — только Boeing, файл `handbook/boeing.pdf`. Восемь семейств: 707 и 720, 727, 737, 747, 757, 767, 777, 787. На семейство одна глава: фотография, чертёж с видами (Wikimedia Commons, Julien Scavini, CC BY-SA 3.0) и таблица пассажирских моделей. Грузовые варианты в таблицу не включены. Оглавление и закладки PDF открывают семейство. Страница `handbook/index.html` даёт ссылку на скачивание.

Цифры — типовые опубликованные значения представительной модификации. Сечения схематические. Для конкретного борта действуют РЛЭ и документация эксплуатанта.
