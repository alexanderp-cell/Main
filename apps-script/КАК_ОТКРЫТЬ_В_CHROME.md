# Quote Desk навсегда в Chrome (Google)

Временные ссылки (trycloudflare) гаснут.  
Этот вариант живёт в **вашем Google-аккаунте** и открывается в Chrome постоянно.

Нужен аккаунт почты, где лежат квоты: **miguelbustos@kt-mnt.com**.

---

## Шаг 1. Откройте редактор скриптов

1. В Chrome откройте: https://script.google.com  
2. Войдите как `miguelbustos@kt-mnt.com`  
3. Нажмите **Новый проект** (New project)

---

## Шаг 2. Вставьте код `Code.gs`

1. Слева файл обычно называется `Code.gs`  
2. Удалите весь текст внутри  
3. Откройте в репозитории файл `apps-script/Code.gs`  
4. Скопируйте **весь** текст → вставьте в редактор Google  
5. Нажмите **Сохранить** (иконка дискеты)

---

## Шаг 3. Добавьте страницу `Index`

1. Слева нажмите **+** рядом с «Файлы» / Files  
2. Выберите **HTML**  
3. Назовите файл точно: `Index` (без `.html` в имени — Google сам добавит)  
4. Удалите содержимое  
5. Откройте `apps-script/Index.html` из репозитория  
6. Скопируйте **весь** текст → вставьте  
7. **Сохранить**

---

## Шаг 4. Опубликуйте как веб-приложение

1. Сверху справа: **Развернуть** → **Новое развёртывание**  
   (Deploy → New deployment)  
2. Нажмите шестерёнку ⚙️ → тип **Веб-приложение** (Web app)  
3. Заполните:
   - **Описание:** `Quote Desk`
   - **Запуск от имени:** `От моего имени` (Me)
   - **У кого есть доступ:** `Только я` (Only myself)  
4. Нажмите **Развернуть** (Deploy)  
5. Если Google попросит разрешения — **Разрешить** доступ к Gmail  
6. Скопируйте **URL веб-приложения** — это ваша постоянная ссылка

---

## Шаг 5. Пользуйтесь

1. Откройте скопированный URL в Chrome (лучше закрепить вкладку / добавить в закладки)  
2. Вставьте партийный номер  
3. **Найти предложения**  
4. **Копировать TSV** → вставить в ТУЗ (колонки O–AA)

---

## Если что-то не так

- Пустая страница / ошибка доступа → вы вошли не в тот Google-аккаунт  
- Просит авторизацию снова → нажмите Разрешить для Gmail  
- После правок кода: **Развернуть → Управление развёртываниями → Изменить → Версия: Новая → Развернуть**

Пришлите мне полученный URL — сохраню в инструкции проекта.
