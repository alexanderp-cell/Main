# TUZ performance reports — download tip (Windows)

These reports are **plain HTML** (tables + CSS only, no scripts, no executables).

Prefer downloading the `.html` file directly.

Do **not** use the old `.zip` packs on Windows: Defender / SmartScreen often
flags `ZIP + HTML` as a false positive (the same pattern is used in phishing
“HTML smuggling” kits). The archive is not malware — Windows just distrusts
that packaging.

Open the downloaded `.html` in any browser (Chrome, Edge, Firefox).
