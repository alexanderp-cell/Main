## 1. Суть задачи

Есть два исходных Excel-файла:
- **`ОБРАЗЕЦ.xlsx`** — эталон того, как должна выглядеть готовая таблица
  (структура, порядок столбцов, оформление). Лист `Stock FAI ...`.
- **`ОСТАТКИ.xlsx`** — актуальные складские остатки авиационных запчастей в
  «грязном»/неструктурированном виде, с цветовой разметкой строк. Лист `Лист1`.

Нужно ежемесячно формировать файл **`ГОТОВЫЕ_ОСТАТКИ.xlsx`**: взять данные только из
`ОСТАТКИ.xlsx`, привести к виду `ОБРАЗЕЦ.xlsx`, ничего не выдумывая.

Решение оформлено как Python-скрипт **`generate_ready_stock.py`** (зависимость —
`openpyxl`), запуск:
```bash
pip install -r requirements.txt
python3 generate_ready_stock.py
```

Итоговые столбцы (как в образце):
`Part Number | Alt. PN | DESCRIPTION | Quantity | Condition | AC Type`.

## 2. Исходное техническое задание (первое сообщение с требованиями)

Дословные требования заказчика к итоговому файлу:

1. Итоговая таблица — такая же структура, порядок столбцов и оформление, как `ОБРАЗЕЦ.xlsx`.
2. Все данные — только из `ОСТАТКИ.xlsx`. Нельзя придумывать отсутствующую информацию.
3. В готовом файле не должно быть кириллицы. Удалить русский текст из значений ячеек.
4. В столбце основного Part Number — только партийный номер.
5. В столбце альтернативных Part Numbers — только альтернативные партийные номера.
6. Удалить из партномеров и альтернативных партномеров лишние слова и обозначения:
   `STK, MOW, STOCK, MOSCOW, PN, P/N, PART NUMBER, ALT, QTY, PCS, EA`, названия складов,
   комментарии и прочий текст, не являющийся частью партномера.
7. Не удалять дефисы, точки, косые черты и другие символы, если они — часть партномера.
8. Если альтернативных партномеров несколько — записать через запятую.
9. Удалить все строки, которые НЕ зелёные (красные, фиолетовые, жёлтые и любые другие).
10. Удалить все строки, где буквы написаны НЕ чёрным цветом.
11. Отсортировать позиции по типам самолётов в том же порядке, что в `ОБРАЗЕЦ.xlsx`.
12. Внутри каждого типа — сортировать по основному Part Number.
13. Если тип самолёта определить нельзя — не угадывать, помещать такие позиции в конец.
14. Сохранить оформление образца: заголовки, шрифты, заливки, границы, ширину столбцов,
    высоту строк, выравнивание, фильтры, закрепление строк, форматы чисел.
15. Сделать простой скрипт, запускаемый в терминале; сразу запустить и сформировать файл.
16. Исходные `ОБРАЗЕЦ.xlsx` и `ОСТАТКИ.xlsx` не изменять.
17. После создания проверить: открывается ли файл; нет ли кириллицы; нет ли слов
    `STK, MOW, STOCK, MOSCOW, PN, P/N` в столбцах партномеров; правильно ли расположены
    столбцы; сохранилось ли оформление; выполнена ли сортировка по типам самолётов.

## 3. Что было выяснено при анализе файлов (ключевые факты)

- **Сопоставление столбцов** (в исходном `ОСТАТКИ`): `Факт P/N → Part Number`,
  `Alt PN → Alt. PN`, `DESCRIPTION → DESCRIPTION`, `Факт QTY → Quantity`,
  `СОСТОЯНИЕ → Condition`, `Тип ВС → AC Type`.
- **Цвет «хороших» строк** — заливка `FF00FF00` (ярко-зелёная). Остальные заливки
  (красная `FFFF0000`, голубая `FF00FFFF`, жёлтая `FFFFFF00`, синяя `FF4A86E8`,
  розовая `FFEA9999`, серая `FFB7B7B7`) — удаляются.
- **Чёрный текст** — это `FF000000` или тема `theme 1` (по умолчанию чёрный).
  Не-чёрные (`FF1F1F1F` тёмно-серый, красный) — строки удаляются.
- **Тип ВС** заполнен не у всех строк. Значения-мусор (`0`, `00-01-1900`, `#N/A`,
  пусто) — считаются неопределимыми и уходят в конец.
- **Порядок типов ВС** берётся по первому появлению в `ОБРАЗЕЦ.xlsx` (не по алфавиту).
- **Кириллица** в `Alt PN` — это комментарии («есть», «продажа со склада»…), не номера.
- В `Тип ВС` встречается `В737` с кириллической «В» → нужно привести к `B737`.
- Партномера-даты: Excel превращает значения вроде `8296-01-01` в даты; их нужно
  выводить как `8296-01-01`, а не `8296-01-01 00:00:00`.
- Количество иногда записано как `1 500` (неразрывный пробел — разделитель тысяч) → `1500`.
- Оформление образца: заголовок — Arial 10 bold, заливка `theme4`, высота строки 52.5;
  данные — Arial 9, белая заливка, тонкие границы, выравнивание по центру, высота 26.35;
  нет объединённых ячеек, нет закрепления и автофильтра.

## 4. История доработок (хронология уточнений заказчика)

1. **Базовая версия.** Фильтрация зелёных строк с чёрным текстом, очистка партномеров,
   удаление кириллицы, сортировка по типам ВС как в образце, сохранение оформления
   (образец используется как шаблон вывода). Проверки пройдены.
   Первый результат: 2707 строк.

2. **Проверка на ошибки + сравнение с образцом.** Найдены и исправлены:
   партномера-даты (`8296-01-01 00:00:00` → `8296-01-01`); количество `1 500` → `1500`;
   удалён `PC` из «мусорных» слов (ломал `PC-1067`); убраны случаи, где Alt PN дублировал
   основной номер. Дубликаты строк — это нормально (в образце тоже есть), не ошибка.

3. **Объединение дубликатов по Part Number.** Разные поставки одного компонента
   не суммировались — теперь одинаковые PN объединяются в одну строку, Quantity
   суммируется. Результат: 2707 → 2086 строк; суммарный остаток сохранён (77 505 шт).

4. **Объединение с учётом состояния.** Объединять только при совпадении И Part Number,
   И состояния. Позиции с одним PN, но разными состояниями (`NEW`/`OH`) — отдельные
   строки. При этом `NE` и `NEW` (и `New`) — это одно и то же (приводятся к `NEW`).
   Результат: 2129 строк. Исправлен баг: единичное нечисловое количество (`3.6 FT`)
   больше не получало лишний префикс `0`.

5. **Ежемесячные обновления.** Далее заказчик присылает `ОСТАТКИ <дата>.xlsx`, и нужно
   каждый раз формировать обновлённый `ГОТОВЫЕ_ОСТАТКИ.xlsx` «как обычно» и сравнивать
   с предыдущим выпуском (сколько строк/компонентов изменилось).

6. **Привязка столбцов по заголовкам.** В одной из выгрузок пропал столбец `СОСТОЯНИЕ`,
   в другой добавился `Serial number`. Поэтому столбцы входного файла определяются
   по тексту заголовка, а не по фиксированному номеру. Лишние столбцы игнорируются;
   отсутствующие — остаются пустыми (ничего не выдумываем).

7. **Усиленная очистка Alt PN** (по отдельной просьбе: в Alt PN — только партномера):
   удаляются англоязычные комментарии (`offered from`, `quoted from`, `moq`), складские
   пометки (`STK`, `MSK`, `REL`, `AMDT`, `STOCK`), выражения (`7 + 7`) и «научная» запись
   Excel (`7.70051e+18`); несколько номеров через пробел корректно разделяются
   (`MS24665-91 MS24665-96`), а случайно разорванные пробелом — склеиваются
   (`P01074-101 WC` → `P01074-101WC`); чисто числовые токены короче 4 знаков не считаются
   номерами.

## 5. Итоговая логика скрипта `generate_ready_stock.py`

1. **Определение столбцов входного файла по заголовкам** (устойчиво к перестановкам
   и лишним/отсутствующим столбцам).
2. **Фильтрация строк:** оставляем только зелёные (`FF00FF00`) с чёрным текстом
   (`FF000000` или `theme 1`).
3. **Очистка значений:**
   - удаление кириллицы из всех значений; транслитерация кириллических двойников в типе
     ВС (`В737` → `B737`);
   - даты → `ГГГГ-ММ-ДД` (восстановление партномеров-дат);
   - количество: `1 500`/неразрывные пробелы → число; нечисловые с единицами (`3.6 FT`)
     сохраняются как есть;
   - основной Part Number: удаление служебных слов, сохранение `-`, `.`, `/`;
   - Alt PN: только настоящие партномера (см. п.4 выше), несколько — через запятую.
4. **Объединение** строк с одинаковой парой (Part Number + Состояние): Quantity
   суммируется; Alt PN и AC Type объединяются как уникальные значения; DESCRIPTION —
   самое частое; `NE`/`New` → `NEW`. Строки без Part Number не объединяются.
5. **Сортировка:** по типам ВС в порядке их первого появления в образце; определимые
   типы не из образца — после; неопределимые (пусто/`0`/`#N/A`/`00-01-1900`) — в конец.
   Внутри — по основному Part Number, затем по состоянию.
6. **Запись в шаблон:** образец загружается как основа вывода, строки данных заменяются
   новыми, стиль ячеек (шрифт/заливка/границы/выравнивание/формат) берётся из строки
   образца, высоты строк и ширины столбцов сохраняются. Итог сохраняется в
   `ГОТОВЫЕ_ОСТАТКИ.xlsx`. Исходные файлы не изменяются.

Набор обязательных проверок результата (прогоняются каждый раз):
открывается ли файл; нет ли кириллицы; нет ли шумовых слов в партномерах; в Alt PN —
только номера; нет дублей (PN + состояние); `NE` приведены к `NEW`; нет партномеров-дат
со временем; оформление/ширины/высоты как в образце; сортировка без нарушений.
